## 📌 О проекте

Проект представляет собой набор автоматизированных API-тестов для сервиса **[Stellar Burgers](https://stellarburgers.education-services.ru/)**.

Цель проекта — проверить корректность работы основных API-эндпоинтов, предусмотренных заданием:

* создание пользователя;
* авторизация пользователя;
* создание заказа;
* обработка некорректных запросов;
* проверка кодов ответа и содержимого JSON-ответов.

Для разработки тестов использовалась документация API:

📄 **[Документация API Stellar Burgers](https://code.s3.yandex.net/qa-automation-engineer/python-full/diploma/Api-Stellar_Burgers.pdf)**

# 🧩 Фикстура `create_user`

В файле `conftest.py` реализована фикстура:

```python
@pytest.fixture(scope="function")
def create_user():
```

Фикстура выполняет полный жизненный цикл тестового пользователя:

```text
Генерация данных
       ↓
Создание пользователя
       ↓
Получение accessToken
       ↓
Передача данных в тест
       ↓
Выполнение теста
       ↓
Удаление пользователя
```

Использование фикстуры позволяет не дублировать код создания и удаления пользователя в каждом тесте.

# 💡 Особенности проекта

В проекте применены следующие подходы:

* **Page Object-подобное разделение API-методов и тестов**;
* использование **pytest-фикстур** для подготовки и очистки тестовых данных;
* использование **pytest.mark.parametrize** для проверки нескольких сценариев;
* генерация случайных данных с помощью **Faker**;
* вынесение URL в отдельный модуль;
* вынесение ожидаемых сообщений API в отдельный модуль;
* использование **Allure** для подробного отображения результатов тестирования;
* использование `requests` для взаимодействия с REST API.
